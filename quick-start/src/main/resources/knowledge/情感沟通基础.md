# 情感沟通基础手册

本手册为「心屿」情感助手的内置知识库，包含关系阶段判断、信号解读、话术模板与沟通原则。

## 一、关系阶段判断标准

根据双方互动特征，相亲/恋爱关系可划分为六个阶段。判断需综合多项信号，不可单凭一点下结论。

**初识破冰期**：刚认识，聊天以基本信息交换为主，回复间隔可能较长（几小时到一天）。此阶段重点是建立舒适感，不急于推进关系。

**试探接触期**：开始出现主动提问（问及喜好、周末安排），回复速度缩短到半小时内，会使用表情包。此阶段可适度释放好感信号。

**暧昧升温期**：出现夜间长聊（22点后持续对话超过1小时）、主动分享日常琐事、使用亲昵称呼。此阶段是关系推进的关键窗口。

**确认关系期**：开始讨论未来安排（一起旅行、见朋友），肢体距离缩短，主动介绍给社交圈。

**稳定磨合期**：出现分歧与摩擦，需要建立冲突处理机制。

**冷淡倒退期**：回复间隔重新拉长、话题变浅、主动发起次数显著下降。连续出现三项以上即为预警信号。

## 二、关键信号解读

**回复速度**：不能孤立看单次回复时长，要看趋势。同一个人从10分钟变成3小时，且持续三天以上，才构成信号。

**回复长度**：如果对方回复从多句变成单字（"嗯""好""知道了"），且不再延续话题，是参与度下降的表现。

**话题发起方**：统计一周内谁先开启对话。健康的关系中双方发起比例大致接近4:6到6:4。若长期低于2:8，说明投入不对等。

**未来时态**：对方是否在对话中使用"我们下次""以后可以"这类未来指向的表述。缺乏未来时态通常意味着对方将关系限定在当前。

## 三、三阶回应法

「三阶回应法」是本手册推荐的核心沟通方法，适用于对方表达情绪或抱怨的场景。

第一阶：**情绪接住**。先复述并承认对方的感受，不辩解、不急于解决问题。示例："听起来你今天真的很累，被临时加任务确实让人火大。"

第二阶：**确认需求**。询问对方此刻需要的是倾听还是建议。示例："你现在是想吐槽一下，还是想让我帮你想办法？"

第三阶：**提供选择**。根据对方回答给出具体选项，而非直接给方案。示例："如果想放松，我可以陪你走走；如果想解决，我们明天一起理一下任务清单。"

三阶顺序不可调换。跳过第一阶直接给建议，是最常见的沟通失误，会让对方觉得"你根本没在听"。

## 四、邀约话术模板

**低压力邀约**（适合试探接触期）：
"我周六下午会去XX书店附近，如果你有空可以一起喝杯咖啡，没空也没关系。"

**明确邀约**（适合暧昧升温期）：
"这周末有部片子评价不错，我想约你一起看，周六晚上方便吗？"

**复约话术**（邀约被婉拒后）：
"没关系，那等你方便的时候我们再约。"——不要追问原因，不要连续邀约第二次。

## 五、冷场破冰话术

当对话出现停滞时，避免使用"在干嘛""吃了吗"这类封闭式提问。改用开放式分享加提问的类型：

"今天路过一家川菜馆，排队排到街角，突然想到你之前说喜欢吃辣，你一般能接受多辣？"

结构是「具体场景 + 关联对方信息 + 开放问题」，比直接提问更容易获得长回复。

## 六、核心沟通原则

**不评判**：避免"你这样想不对""你太敏感了"这类表述，改说"我理解你会这么想"。

**不使用绝对化承诺**：关系结果受双方与外部因素影响，任何"这样做一定成功"的说法都不负责任。

**尊重边界**：对方明确拒绝后，不重复施压。连续三次邀约被拒应停止主动邀约，转为等待对方回应。

**区分事实与推测**：表达判断时标注确定性程度。说"他可能最近工作忙"而非"他就是忙"，避免把自己的推测当作事实。
